# 🏛️ 群晖 NAS 原生套件安装指南 (Synology SPK Package)

ReadFlow 提供了官方群晖 DSM 7.x / 6.x 原生套件（`.spk` 安装包），**无需借助 Docker 或复杂的 SSH 命令行**，直接在群晖「套件中心」点几下鼠标即可完成部署，并自动在 DSM 主菜单和桌面上生成应用快捷方式！

---

## 🌟 套件特性

* ⚡ **原生运行**：直接使用群晖官方 Python 3 环境，资源开销极低（内存占用仅约 30MB）。
* 🎨 **DSM 桌面原生图标**：安装完成后在群晖桌面一键直达 Apple Dark 风格控制中心。
* 📝 **可视化安装向导**：安装过程中直接弹出输入框，输入豆瓣 ID、Goodreads ID、邮箱即可，无需手动修改配置文件。
* 🔄 **DSM 进程生命周期托管**：套件中心支持一键「停用」、「启动」、「查看日志」、「卸载」。

---

## 🚀 安装步骤

### 第一步：准备群晖 Python 3 环境
1. 打开群晖 DSM **「套件中心」**。
2. 搜索 **Python 3** 并点击安装（官方免费套件）。

### 第二步：安装 ReadFlow 套件
1. 从 Releases 或本项目 `dist/` 目录下载 `readflow_1.0.0_noarch.spk` 安装包。
2. 打开群晖 **「套件中心」**，右上角点击 **「手动安装」**。
3. 点击 **「浏览」**，选择刚才下载的 `readflow_1.0.0_noarch.spk`，点击「下一步」。
4. 勾选同意第三方套件安装（DSM 7 会提示未知发行者，属于正常提示）。
5. **在弹出的安装向导中填入你的配置**：
   * 豆瓣用户数字 ID（如 `151885595`）
   * 电纸书收件邮箱（如 `your_email@163.com`）
   * 发信 SMTP 服务器与授权码（如 `smtp.163.com`）
6. 点击「完成」，套件将自动启动！

### 第三步：访问与使用
1. 打开群晖 DSM 左上角**「主菜单」**，可以看到 **ReadFlow** 图标。
2. 点击图标即可直接在浏览器新标签页打开控制中心（默认端口 `8765`）：
   `http://<你的群晖IP>:8765`
3. 以后只要在手机豆瓣或 Goodreads 上标记「想读」，群晖后台将自动静默下载并推送到你的电纸书！

## 🛠️ 自行打包 SPK（开发者）

如果你修改了源码想要自行打包群晖套件，只需在项目根目录下执行：

```bash
python3 synology/build_spk.py
```

打包完成后，将在 `dist/readflow_1.0.0_noarch.spk` 生成最新的安装包。
